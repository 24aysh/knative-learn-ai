    6. Is Docker/Podman available?
    7. Is a registry configured?
    8. Can the registry be pushed to?
    9. Is Git initialized?
    10. Is GitHub remote configured?
    11. Are GitHub Actions secrets configured?
    12. Can func config ci generate the workflow?
    13. Can deployment actually work?
